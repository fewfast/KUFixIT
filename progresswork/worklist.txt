**** Feature ที่ต้องการให้เพิ่ม ****


หลังจากที่แอดมินกดตกลงในการส่งงานของช่างแล้ว
- ให้นำข้อมูล true false เก็บเพิ่มไว้ใน table ticketid งานที่ช่างทำ (column fix_history_progress) หาก อันไหนเป็น true ให้ device นั้นๆมี status เป็น finish อันโนมัติ โดยที่ไม่ต้องสน ค่า false index ที่ตามหลังมา จากนั้นให้เอาเวลา next_fix_date_start และ next_fix_date_end ออกจาก tableFixlist row เดียวกับ ticketed ที่ทำ
- เก็บรูปไว้ใน storage bucket folder technician-work-results และหา subfolder ที่มีชื่อเดียวกับ id ticket งานนั้น หากไม่มีสร้างใหม่ ขนาดตาม (device ใน ticket * 2 MB) รูปที่เก็บเปลี่ยนชื่อเป็น เลข 1 2 3 ตาม device 
- ลบ ticketid ออกจาก database table uid ของทีมช่าง

หากช่างซ่อมไม่ทันในเวลา login ถือว่าไม่มีอะไรเสร็จสิ้น และ comment ใช้เป็น ซ่อมไม่สำเร็จ แต่เอา ticketid ออกเหมือนเดิม เอา next_fix_date_start และ next_fix_date_end ออก status แทนเป็น false ทุกอุปกรณ์

**--ในหน้า ติดตามงานซ่อม--**
ใน column ช่วงเวลาที่เช้าซ่อมครั้งถัดไป
-ให้เอาเวลา next_fix_date_start และ next_fix_date_end มาโชว์ (รูปแบบดังนี้ next_fix_date_start - next_fix_date_end)
จะมีปุ่ม ประวัติการซ่อมให้กดได้ ซึ่งพอกดไปตอนนี้จะยังไม่มีประวัติการซ่อม

- สิ่งที่ต้องการให้ทำคือ ทำตารางแสดงประวัติการซ่อมพร้อมรูปผลลัพธ์งานโดยcolumn ที่ต้องการคือ
ช่วงเวลาซ่อม(เป็นช่วงเวลาที่ช่างทีมนั้นๆสามารถเข้าสู่ระบบได้)
